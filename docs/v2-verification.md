# LoopDesk v2 검증 결과

2026년 11월 23일 · Windows 개발 환경

**통과**는 표에 적힌 범위의 결과를 직접 확인했다는 뜻입니다. **부분 확인**은 동작의 일부를 확인했거나 실제 대상 창 시험이 남았다는 뜻입니다. 시중 제품 비교는 앞선 보고서의 공식 문서 조사 결과이며, 이번 시험은 LoopDesk를 대상으로 했습니다.

| 항목 | 결과 | 확인한 내용과 남은 시험 |
|---|---|---|
| 01. Q 10회 | 부분 확인 | 입력 추가, 설정 저장, 엔진의 10회 반복 순서를 확인했습니다. 메모장 수신과 첫 사용자 시험이 남았습니다. |
| 02. 녹화 시작·종료 | 부분 확인 | 창 숨김·복원, 녹화 파일의 키 누름·뗌 변환을 확인했습니다. 실제 abc 녹화 후 다른 창에서 재생하는 시험이 남았습니다. |
| 03. 조합키·한글 | 부분 확인 | Ctrl 조합과 한글이 저장 후 보존되는 것을 확인했습니다. 전용 테스트 창의 한글 전송은 한 시도에서 수신되지 않았고, 재시도는 포커스를 얻지 못했습니다. 한글 IME 녹화와 복사·붙여넣기도 실제 창에서 추가 확인이 필요합니다. |
| 04. Enter·숫자패드·길게 누르기 | 부분 확인 | 108키와 길게 누르기 설정을 확인했습니다. 실제 Windows 수신 메시지와 누름 시간은 확인하지 못했습니다. |
| 05. 클릭·휠·드래그 | 부분 확인 | 새 마우스 그림의 좌·우·가운데와 휠 위·아래 다섯 조작이 각각 맞는 동작으로 추가됐습니다. 더블클릭·드래그를 외부 앱에서 재생하는 시험이 남았습니다. |
| 06. 좌표·배율 | 미검증 | F10 실측, 창 이동, 배율 100%·150%, 혼합 배율 모니터 시험이 남았습니다. |
| 07. 동작·묶음·전체 반복 | 부분 확인 | 동작과 묶음 실행 순서 및 풀기·다시 적용을 확인했습니다. 실제 대상 창에서 총 18글자가 수신되는지 확인이 필요합니다. |
| 08. 대기·랜덤 | 부분 확인 | 0.1초에 ±40%를 적용하는 계산을 검증했습니다. 수신 시각으로 측정한 분포는 미확인입니다. |
| 09. 일시정지·재개·정지 | 부분 확인 | 일시정지 상태의 진행 차단, 재개 위치, 취소 및 트레이 단축키 연결을 확인했습니다. 외부 앱에서 긴급 정지 후 눌림이 남는지는 미확인입니다. |
| 10. 단축키·창 닫기 | 부분 확인 | 등록, 내부 키 충돌 탐지, 창을 닫은 뒤 백그라운드 제어를 확인했습니다. 다른 앱과의 단축키 충돌 및 실제 키 변경 시험이 남았습니다. |
| 11. 이미지·색상·글자 대기 | 부분 확인 | 준비된 이미지의 위치를 찾았고, Windows OCR은 영문 예제를 인식했습니다. 실화면 색상 대기, 한글 인식, 비슷한 버튼의 오클릭과 실패 분기는 미확인입니다. |
| 12. 대상 창·예약 | 부분 확인 | 대상 앱이 활성화되지 않은 예약이 건너뛰어지고 내역이 남는 것을 확인했습니다. 예약 실제 실행과 재생 도중 창 전환은 미확인입니다. |
| 13. 설치·업데이트·복구 | 부분 확인 | ZIP 내부 세 파일의 무결성과 이전 저장본 자동 백업, 설정 재열기를 확인했습니다. 기존 임시 폴더 오류가 발생한 PC에서 설치가 끝나는지와 다른 계정에서 관련 파일까지 복구되는지는 미확인입니다. |

이전 보고서에서 제안한 첫 사용자 3명 시험은 아직 실시하지 않았습니다. 시중 앱을 설치해 같은 조건에서 실행하는 비교 시험도 실시하지 않았습니다.
